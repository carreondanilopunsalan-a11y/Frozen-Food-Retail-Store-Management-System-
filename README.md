# Web-Based Inventory Management System for Frozen Food Retail Store

## About the Project

Inventory Management System for Frozen Food Retail Store is a web-based system designed to help manage the inventory and sales of a retail store. It provides a simple way to organize products, track sales, manage suppliers, and view store reports.

## Features

- **Dashboard** – Displays a summary of the store's information.
- **Catalog** – Allows users to view and manage products.
- **Sales** – Used to record and monitor sales.
- **Adjustment** – Helps manage inventory adjustments.
- **Suppliers** – Keeps supplier information organized.
- **Reports** – Provides reports about the store.
- **System Settings** – Contains the system's settings.

## How to Run the Project

1. Download or copy the project files.
2. Find the `index.html` file.
3. Open it in a web browser, such as Google Chrome.
4. The system interface will appear in your browser.

## Purpose

This project was created to make inventory and sales management easier and more organized. It helps users manage product information and other store records in one place.
